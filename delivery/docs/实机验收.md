# 0.1.6 升级及实机反馈（employee_id: delivery）

本轮修复单一候选窗、完整候选页及布局后高亮滚动、短页宽度收缩。实际桌面仍为 NOT_DEPLOYED，修复效果待实机反馈。
安装版 0.1.6 对应装配 0.2.9；0.1.5 及更早产物原样保留。
以下命令由用户在自己的服务器桌面终端执行；不要提交凭据、桌面授权文件或套接字。

## 升级、启动和应用入口

在项目根执行；P、D、S、C 必须沿用原安装的前缀、数据、运行状态和配置路径。
下面展示默认值；若原安装使用其他路径，请替换，避免误用空词库或默认设置。

```sh
P="$HOME/.local/opt/server-ime"
D="$HOME/.local/share/server-ime"
S="$HOME/.cache/server-ime/run"
C="${XDG_CONFIG_HOME:-$HOME/.config}/server-ime/settings.json"
python3 delivery/bin/ime-install list --prefix "$P"
"$P/bin/server-ime" --state-dir "$S" stop
python3 delivery/bin/ime-manifest inspect delivery/dist/server-ime-0.1.6.tar.gz
python3 delivery/bin/ime-install upgrade delivery/dist/server-ime-0.1.6.tar.gz --prefix "$P" --data-dir "$D" --retain 3 --json
python3 delivery/bin/ime-install verify --prefix "$P"
"$P/bin/server-ime" --config "$C" --data-dir "$D" --state-dir "$S" start --managed-ibus
"$P/bin/server-ime" --state-dir "$S" exec -- xfce4-terminal --disable-server
"$P/bin/server-ime" --state-dir "$S" status
```

首次安装把 upgrade 改为 install，略过旧版 list/stop。已有应用需退出后经 exec 重开，
例如 `exec -- gedit --standalone`；浏览器要避免复用原进程，具体方式见 integration/docs/application-compatibility.md。
已有 IBus 路径可在自己的会话 `export IBUS_ADDRESS=$(ibus address)` 后使用 `start`（省略 --managed-ibus）。
所有控制命令保持同一 S；本步骤不访问你的桌面授权文件与共享套接字。

## 双框与候选布局检查

在 settings 中分别保存 page_size=9/max_visible=3 和 page_size=5/max_visible=1；检查整页候选可滚动到达、高亮自动可见、末项鼠标及数字提交、翻页后短页宽度收缩。max_visible 只限制视口宽度，不改变逻辑页和编号。

键入 `nihao`，观察一个自绘候选窗及正常应用预编辑；数字或鼠标选词后候选窗隐藏。
窄屏放不下时通过可见的横向滚动条查看并点击本页全部候选，高亮自动进入视野；编号和完整 ID 保留，Page Down 仅切换逻辑页。默认同页候选从左到右排列，翻页后仍横排；长候选省略不改变提交原文。旧配置无 layout 项即横排，显式 vertical 偏好保留。
检查 `nihao,` 的中文提交与标点，以及混输和切换焦点；Esc 可取消当前拼音组合。
本版不提供连续联想，无联想开关；若从历史联想版升级，先 stop 再启动本版即可撤销该行为；Esc 仅取消当前拼音。仅抑制本引擎原生 lookup/auxiliary，不关闭系统面板。
隔离检查通过不代表你的桌面问题已解决。

## 回滚与数据

```sh
"$P/bin/server-ime" --state-dir "$S" stop
python3 delivery/bin/ime-install rollback --prefix "$P" --to 0.1.5 --json
python3 delivery/bin/ime-install verify --prefix "$P"
"$P/bin/server-ime" --config "$C" --data-dir "$D" --state-dir "$S" start --managed-ibus
"$P/bin/server-ime" --state-dir "$S" exec -- xfce4-terminal --disable-server
```

如需回到上一安装版本，省略 --to；也可指定仍保留的 0.1.2（历史版包含已撤回的联想）。升级/回滚保留外部配置 C 和 D/learning；
不会自动备份用户随后手动修改的数据。词库导出、备份和恢复见使用指南第 5 节。

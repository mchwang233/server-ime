# server-ime 中文使用与运维指南（0.1.6）

当前正式版 0.1.6，装配 0.2.9；旧包 0.1.0/0.1.1/0.1.2/0.1.3/0.1.5 保留。摘要以 `dist/SHA256SUMS` 和 `manifest/lock.json` 为准。
升级、启动、取消组合、回滚及一次反馈入口见 [实机验收.md](实机验收.md)。

## 1. 安装前检查

```sh
(cd delivery/dist && sha256sum -c SHA256SUMS)        # 全部 OK
python3 delivery/bin/ime-manifest inspect delivery/dist/server-ime-0.1.6.tar.gz
python3 delivery/tests/check_feedback_release.py   # 许可材料/中文说明/源码包/工具逐项核对
python3 --version                                   # >= 3.9
python3 -c "import gi; gi.require_version('IBus','1.0'); gi.require_version('Gtk','3.0')"
ibus-daemon --version                               # >= 1.5.25
```

`ime-install` 会拒绝系统目录、相对路径、`$HOME` 本身、数据目录与前缀互相包含等情况，并返回退出码 2。

## 2. 安装 / 重复安装

```sh
python3 delivery/bin/ime-install install delivery/dist/server-ime-0.1.6.tar.gz \
    --prefix "$HOME/.local/opt/server-ime" \
    --data-dir "$HOME/.local/share/server-ime" --json
```

- 前缀内容：`ime/versions/<版本>/`（载荷）、`ime/current -> versions/<版本>`、`bin/server-ime`（唯一入口软链）、
  `ime/state/installed.json`（记录版本、逐文件哈希、入口、数据目录）、`ime/log/install.log`（仅路径与哈希）。
- 重复执行同一条命令是幂等的（已实测：第二次安装返回 0，版本与文件哈希不变）。
- 数据目录只创建空子目录 `learning/`（0700），不写入任何内容。

## 3. 启动、切换与退出

```sh
# 产品自带受管 IBus（只影响经 exec 启动的应用，不影响用户桌面输入法）
"$HOME/.local/opt/server-ime/bin/server-ime" \
    --data-dir "$HOME/.local/share/server-ime" \
    --state-dir "$HOME/.cache/server-ime/run" start --managed-ibus

# 用该输入法的应用
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" \
    exec -- xfce4-terminal --disable-server

"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" status
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" stop
```

- 已有 IBus 会话：`export IBUS_ADDRESS=$(ibus address)` 后执行 `start`（不终止既有 daemon，停止时还原原引擎）。
- 中英切换 `Ctrl+Space`；空格/数字/鼠标选词；Page Up/Down 翻页；`Enter` 提交原拼音；`Esc` 取消；`Tab` 交还焦点。
- 无图形会话时 `start` 会失败：需要可用的 `DISPLAY` + `XAUTHORITY` 和会话总线
  （本机验证用 Xvnc + MIT cookie + 私有 D-Bus，见 `docs/evidence-index.md`）。
- 同一 `--state-dir` 拒绝重复启动；socket 路径过长会明确报错，请用较短的 state 目录。

## 4. 设置界面与配置文件

```sh
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" settings
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" config get
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" config apply 新设置.json
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" config reset
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" learning-status
"$HOME/.local/opt/server-ime/bin/server-ime" --state-dir "$HOME/.cache/server-ime/run" reload-lexicon
```

| 数据 | 路径 |
| --- | --- |
| 用户设置 | `$XDG_CONFIG_HOME/server-ime/settings.json`（默认 `~/.config/server-ime/settings.json`，0600 原子写；可用 `--config` 或 `SERVER_IME_CONFIG` 覆盖） |
| 个人词库 / 学习数据 | `<--data-dir>/learning/`（`words.jsonl`、`meta.json`、`audit.jsonl`、`backups/`） |
| 运行状态 | `<--state-dir>/`（`status.json`、进程日志、私有控制 socket） |
| 安装文件 | `<--prefix>/ime/versions/<版本>/`，入口 `<--prefix>/bin/server-ime` |

设置项涵盖候选每页数量、字号、中文标点、快捷键、双拼（当前仅自然码）、模糊音与纠错规则、学习开关；
能力门控由真实引擎能力决定，非法值以结构化错误拒绝，不会静默保存成功。

## 5. 个人词库的导入 / 导出 / 备份

```sh
python3 lexicon/bin/lexicon --data-dir "$HOME/.local/share/server-ime/learning" status
python3 lexicon/bin/lexicon --data-dir "$HOME/.local/share/server-ime/learning" export --out 导出.json
python3 lexicon/bin/lexicon --data-dir "$HOME/.local/share/server-ime/learning" import 导出.json
python3 lexicon/bin/lexicon --data-dir "$HOME/.local/share/server-ime/learning" backup
python3 lexicon/bin/lexicon --data-dir "$HOME/.local/share/server-ime/learning" verify
```

导入/恢复后执行 `reload-lexicon` 让运行中的引擎重新加载。格式为 `ime-lexicon-user/1`、
`ime-lexicon-user-bundle/1`、`ime-lexicon-backup/1`（见 `lexicon/format/`）。

CLI 的 --data-dir 必须与 Engine.user_data_dir 一致，即产品 --data-dir 下的 learning 子目录。

## 6. 升级、回滚、卸载与恢复

```sh
# 升级（必须已安装）
python3 delivery/bin/ime-install upgrade delivery/dist/server-ime-0.1.6.tar.gz \
    --prefix "$HOME/.local/opt/server-ime" --data-dir "$HOME/.local/share/server-ime" --json
# 回滚到上一版本（或 --to <版本>）
python3 delivery/bin/ime-install rollback --prefix "$HOME/.local/opt/server-ime" --json
# 列版本 / 校验已安装文件
python3 delivery/bin/ime-install list   --prefix "$HOME/.local/opt/server-ime"
python3 delivery/bin/ime-install verify --prefix "$HOME/.local/opt/server-ime"
# 卸载（默认保留数据目录、无关文件与冲突备份）
python3 delivery/bin/ime-install uninstall --prefix "$HOME/.local/opt/server-ime" --json
# 事务被中断（崩溃/断电）后恢复
python3 delivery/bin/ime-install recover --prefix "$HOME/.local/opt/server-ime"
```

- 升级与回滚都不改动数据目录；切换点是 `ime/current` 的原子软链。
- `--retain N` 控制保留的版本目录数；只有 `--purge-data --yes` 才会删除个人数据。
- 退出码：0 成功；2 参数/策略拒绝；5 校验失败或文件漂移；6 前缀被并发占用；90 故障注入（仅测试）。

## 7. 诊断

```sh
python3 delivery/bin/ime-diagnose --prefix "$HOME/.local/opt/server-ime" \
    --data-dir "$HOME/.local/share/server-ime" --json
```

输出环境、策略、版本、逐文件哈希、运行依赖探测（python3 / ibus-daemon / dbus-daemon / gi /
包内 libpinyin 运行时与词库表）、入口状态、数据目录清单（只列路径、大小、权限、哈希）。
**不包含任何输入内容或个人词条文本。**

## 8. 故障排查

| 现象 | 原因 / 处理 |
| --- | --- |
| `start` 返回 `panel exited before ready`，`panel.log` 有 `Gtk couldn't be initialized` | 没有可用的 X11 授权。检查 `DISPLAY`、`XAUTHORITY`；本机隔离验证用 Xvnc TCP + MIT cookie（`integration/checks/run_checks.py`），真实桌面用自己的会话变量 |
| `start` 返回 `Explicit DISPLAY and DBUS_SESSION_BUS_ADDRESS are required` | 未设置会话总线；在桌面会话内运行，或 `dbus-run-session -- …` |
| `socket path too long` / state 目录报错 | 用较短的 `--state-dir`（如 `~/.cache/si/run`） |
| `ibus-daemon: command not found` | 缺少 IBus；本产品不做替代实现 |
| 安装报 `位于系统目录 /usr 之下` 或退出码 2 | 前缀必须是用户可写的绝对路径（如 `~/.local/opt/server-ime`） |
| `verify` 报告文件漂移（退出码 5） | 重装同版本加 `--repair`（旧内容移入 `ime/backup/`），或升级/回滚到干净版本 |
| `bin/server-ime` 已存在且非本工具创建 | 先确认归属；用 `--force-conflicts` 会把原文件移入 `ime/backup/`，不会删除 |
| 候选不出现 / 无中文上屏 | 确认应用是经 `server-ime exec --` 启动的，且 `IBUS_ADDRESS` 属于本产品受管 daemon |
| 学习不生效 | 学习默认关闭；在设置中开启或 `learning-status` 查看门控（敏感用途/隐私开关会禁用学习） |

## 10. 标点修复（装配 0.2.1）

直接键入 `nihao,nihao.nihao?nihao!` 可得到 `你好，你好。你好？你好！`；关闭中文标点则使用 ASCII。提交当前高亮候选后继续消费剩余后缀，不重复提交。单引号仍作拼音分隔符。邮箱、网址和版本号已有原文结构中的符号保留。首个点号遇到全小写拼音前缀时存在歧义，输入裸域名可切英文模式，或用小键盘 `KP_Decimal` 插入原文点号；Enter 提交原文。

应用通过范围为隔离 Xvnc + xfwm4；两轮无窗口管理器的焦点失败保留于 integration/evidence/run-20261028-235645 和 run-20261028-235853。

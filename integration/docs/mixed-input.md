# 中文模式下的拼音与原文混输

employee_id: platform；装配 0.2.1 / 引擎 0.4.0，`verifies: []`。

统一入口保持 `integration/bin/server-ime`，搬迁包使用 `bin/server-ime`。
产品直接使用真实 `PlatformSession.convert` → `Session.set_composition`，不在平台复制拼音切分逻辑。
大小写、已有地址/版本结构中的符号和混合片段保持原样；纯拼音末尾的句读符号遵循下述提交规则。

| 当前状态 / 按键 | 行为 |
|---|---|
| 中文模式，有组合，普通字母或符号 | 在原始光标位置插入并重新转换，保持大小写及实际输入的符号 |
| 纯小写拼音组合末尾，`, . ? !` | 提交当前高亮候选；继续选择未消费后缀的首选，再提交映射后的标点。关闭中文标点时使用 ASCII 符号 |
| 拼音中的单引号 | 作为音节分隔符，例如 `xi'an!` → `西安！` |
| `KP_Decimal`（NumLock 开） | 总是插入原文点号，不触发句号提交 |
| 纯拼音位置，顶排 1–9 | 选择当前页对应候选 |
| 原文片段位置（引擎 `literal_digits=true`），顶排数字 | 插入原文数字 |
| 只有原文候选，例如 `v` | 继续插入数字，可以直接输入 `v2.0` |
| 数字小键盘 `KP_0..KP_9`（NumLock 开） | 无论候选状态，都插入原文数字 |
| 空格 / Enter | 分别选择当前候选 / 提交整段原文；无组合的空格传给应用 |
| Up/Down、鼠标 | 显式选择；即使数字正在插入也可以选词 |
| Left/Right、Home/End、Backspace/Delete | 按原始文本坐标编辑，使旧候选失效 |
| 失焦、Tab、Esc、配置更新 | 丢弃未提交的组合，不重放已提交前缀 |
| 无组合时的标点 | 遵循中文标点设置 |

直接输入 `nihao,nihao.nihao?nihao!` 得到 `你好，你好。你好？你好！`，不需要先按空格或数字。
中文标点关闭时得到 `你好,你好.你好?你好!`。当前高亮为分段候选时只提交一次该前缀，
后缀使用重新转换后的首选；例如这版引擎在 `nihao` 上高亮“尼”后按逗号得到 `尼号，`，
其中单独 `hao` 的首选为“号”。无法转换的后缀原样提交，不丢弃也不重放已提交前缀。
光标在组合中间时，标点按原文插入，保留编辑语义。

`,`、`.`、`?`、`!` 之外的组合符号继续传给引擎：`@ : /` 不会提前截断地址，
单引号不会截断拼音。`v2.0`、`nihao@example.org`、`https://example.org/a?v=2` 可直接输入。
尚未形成地址结构的小写前缀也可能是拼音（包括缩写），例如 `ni.hao@example.org`、`www.example.org`；
第一个点号的意图不能从已有按键唯一确定。需要原文时先切到英文模式输入完整地址，
或用小键盘 `KP_Decimal` 输入第一个点号；后续符号保留，按 Enter 或选原文候选提交。
仅含原文候选的前缀（如 `v`）不触发句读提交。此规则不声称自动识别所有邮箱和裸域名。

无需 Ctrl+Space 的例子：输入 `nihaoAPI2shijie` 后按空格得到 `你好API2世界`；
`User+Tag@Example.org`、`https://Example.org/A?v=2` 输入后按空格保留原文。
多个词之间，选词用的空格会被消耗；再按一次空格才在应用中产生词间空格。

纯拼音后的数字意图存在歧义，例如同一顶排 `1` 不能同时表示“第一候选”和原文数字。
要在 `abc` 后插入 `123`，可用小键盘 `1`、再输入顶排 `23`，然后选择 `abc123` 原文候选；
也可在 `abc` 后按 Enter 提交原文，再输入数字。输入 `xian` 等可作拼音也可作英文的文本时，
选择原文候选或按 Enter。平台不靠英文词表猜测意图。

分段示例：输入 `nihaoLinux6.1shijie`，选择 `你好`、`Linux6.1`、`世界`。
平台端口依次提交这三个片段，未消费的原文仍可编辑。第一段提交后不能靠预编辑退格撤回已进应用的文本。
无分隔的全小写中英边界仍可能有歧义；是否提供某个候选由引擎负责，平台不改写候选或补全缺失符号。

密码/PIN 用途在平台入口直接透传，不送入转换与学习。浏览器可能在应用侧禁用 IME，
而不发送 IBus PASSWORD 用途；检查分别记录平台用途门控与浏览器实际无组合/无学习结果。
学习只持久化引擎确认的中文片段，不存邮箱、网址等原文 token。
个人管理工具必须使用 `<产品 --data-dir>/learning`，外部修改后执行 `reload-lexicon`。

复现入口：`SERVER_IME_PRODUCT_ROOT=/绝对路径/integration/build/product python3 integration/checks/run_checks.py --window-manager xfwm4`。
沿用独立 Xvnc + xfwm4 + D-Bus + IBus，通过产品 `start/exec/stop` 启动真实应用。
XTest 的大小写和符号由真实 Shift 按键产生；没有 DOM 赋值或把预期中文直接写入应用。
应用读回及逐步记录索引见 `integration/compatibility.json`；历史证据保留。
